Resources

Free and online

Statistical intuition (interactive)

  • Seeing Theory: probability and distributions (S4), inference (S5–S6), regression (S7)
  • R Psychologist: CIs, power, p-values, Cohen’s d, correlation
  • Guess the Correlation; p-hacker; Spurious Correlations; Datasaurus Dozen

R, data and Quarto

  • Wickham et al., R for Data Science (2e)
  • Grolemund, Hands-On Programming with R
  • PsyTeachR, Data Skills for Reproducible Research
  • Posit cheatsheets (dplyr, ggplot2, purrr, Quarto)
  • Quarto documentation
  • Bryan, Happy Git and GitHub for the useR
  • Stuck? Posit Community, with a minimal reproducible example

Visualisation

  • From Data to Viz; R Graph Gallery
  • Wickham et al., ggplot2; Wilke, Fundamentals of Data Visualization
  • Colour-blind safe palettes: viridis, ColorBrewer

Beyond this course

  • Repeated measures (trials, sessions, recordings per subject) are not independent. Here we average or pair; the proper tool is a mixed model: lme4; Yu et al. (2022), Beyond t test and ANOVA, Neuron.
  • Neuro data in R: Neuroconductor, eegUtils, eeguana, ggseg. Open data: OpenNeuro, OSF …
